### Vault hub and object page wireframe

**Vault hub**


[Top Nav]
[Hero] short curator line about current drops
[Category filters] Prints | Publications | Posters | Apparel | Music | Limited Editions | Archive Objects
[Grid] object cards with micro‑story snippet and availability tag (Limited / Open)
[Featured Drop rail] upcoming or live limited runs
[Footer]


**Vault object page**


[Hero] hero image / gallery
[Title] Artist / Contributor
[Curator Story] context + provenance
[Edition Metadata] edition type, run size, materials, certificate info
[Availability] live inventory or reservation status
[Preview] inline preview (images, audio, PDF excerpt)
[Actions]
  - **Reserve** (soft)
  - **Enquire** (for custom or institutional)
  - **Buy Now** (hidden until explicit intent or direct Vault navigation)
[Related Works] Related Texts | Journal | Razz Issue
[Reservation confirmation] editorial copy: “You’ve reserved this edition. We’ll email next steps.”
[Footer]


**Rules**

- **Reserve** available immediately; **Buy Now** appears after Reserve clicked twice in session OR return visit within 7 days OR direct Vault hub navigation.
- Show exact remaining quantity when ≤ 10.
- Reservation expiry and queue position visible in confirmation.

**Analytics**

- vault_item_view, reserve_click, reservation_confirmed, buy_now_click.

**Discipline page**


[Hero] discipline title and short description
[Examples / Past Work] 3 curated case studies with outcomes and timelines
[Two-step intake]
  Step 1: Select Discipline (preselected)
  Step 2: Brief — Project summary (one sentence); Desired timeline; Budget range; Optional upload
[Submit] Send Enquiry
[Auto-reply] “Thanks — we’ll reply within 48 hours with next steps and a relevant case study.”
[Optional] Schedule consult link after initial review
[Footer]

**Rules**

- Show starting fee ranges to qualify leads.
- Route enquiries to curator inbox with discipline tags; SLA 48 hours.

**Analytics**

- commission_inquiry_start, commission_inquiry_submit, consult_scheduled.

### Handoff notes for designers and engineers

- **CMS**: enforce required fields — related links (≥3), edition metadata, inventory, provenance copy.
- **Components**: build reusable rails (Artist, Related Works, Related Texts) and Edition Strip component with highlight states.
- **Tone**: all CTAs and microcopy use curator/editorial language (Reserve, Join Waitlist, Request Info). Avoid retail phrasing.
